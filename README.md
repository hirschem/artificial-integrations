# Artificial Integrations

Portfolio website for Artificial Integrations LLC. Built with Next.js (App Router), TypeScript, and Tailwind CSS.

This is currently a foundation-only setup. Design and portfolio content have not been built yet.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Scripts

- `npm run dev` — start the development server
- `npm run build` — build for production
- `npm run start` — run the production build
- `npm run lint` — run ESLint
